# Documentation

The [developer manual](manual/README.md) is the community entry point. Its [generated HTML](manual/html/index.html) is checked in so a clone can be read without installing Sphinx or LLVM.

| Directory | Contents |
|---|---|
| [`manual/`](manual/README.md) | RST manual sources, runnable examples, Sphinx configuration, and generated HTML |
| [`design/`](design/) | Detailed architecture and milestone designs, including LLKMap grammar |
| [`reviews/`](reviews/) | Revision-specific acceptance evidence and gap assessments |
| [`superpowers/specs/`](superpowers/specs/) | Detailed design specifications |
| [`superpowers/plans/`](superpowers/plans/) | Implementation plans and task history |

Start with the manual for current usage. The design and review records preserve their original scope and revision; they may describe planned or historical behavior.
