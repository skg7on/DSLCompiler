## Metadata compatibility

Newly bound mapped operations include `node` and `output_values` in `micro.mapping`; movement routes include `consumer_ports`. Old stamped movements lacking enough source/consumer identity are deliberately rejected and should be rebound from their original source and plan. Missing layout assignments are deliberately rejected for rules requiring layouts. Plain legacy mappings without movements still undergo rule/layout validation.

Transform resource and memory fields participate in transformed connection identity. Callers constructing transforms manually may leave them unset; binding chooses a visible modeled vector resource and records it on the emitted operation. Unknown footprint, inaccessible memory or invalid selected resources produce diagnostics, not zero-cost transforms. Hand-written Micro-IR still accepts memory space kinds as well as node IDs.
